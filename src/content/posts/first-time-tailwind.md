I’ve been learning web design and trying to make my projects look less like they were designed in 1995. Up until now, my websites was just a mess of plain HTML index files and helper CSS lines that got super long and confusing. 

Then, some Discord coding friends suggested I look up Tailwind CSS. They were like, "Instead of writing standard styles, just write classes directly in your HTML!" It sounded super messy, but oh my god, it’s amazing.

It’s like building a layout with LEGO blocks! Instead of writing a custom CSS rules file with media selectors, I can literally just type `className="flex flex-col md:flex-row p-6 rounded-lg bg-slate-800 hover:scale-105"` and it just works immediately! At first, my HTML code looked extremely crowded, but once you get used to it, you can design anything in like five minutes.

Look at my personal landing page right now! Designing with Tailwind is so satisfying. Now I want to rewrite all my older projects in it.
